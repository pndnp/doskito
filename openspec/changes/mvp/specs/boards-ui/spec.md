# Boards UI

## Purpose

Экран `/` показывает локальный каталог досок и актуализирует их метаданные через API. Пользователь может создать доску, открыть её по ссылке, скопировать ссылку, переименовать, удалить или забыть доску.

## ADDED Requirements

### Requirement: REQ-BU-1 — Отображение списка досок

Если в localStorage есть хотя бы один slug, `/` SHALL показать список вместо Welcome. Каталог хранится в ключе `doskito_boards` как массив `{ slug, name, color, updatedAt, totalTasks, doneTasks }`.

#### Scenario: Чтение каталога

- **WHEN** пользователь открывает `/`
- **THEN** сохранённые карточки показываются сразу, затем `POST /api/boards/summaries` обновляет метаданные
- **AND** `missingSlugs` удаляются из каталога, изменения сохраняются и отображаются без reload
- **AND** ошибка сети не стирает локальный каталог и показывает ненавязчивое сообщение об устаревших данных

#### Scenario: Повреждённое хранилище

- **WHEN** JSON невалиден или localStorage недоступен
- **THEN** приложение не падает, использует безопасное пустое состояние и сообщает, что список доступен только в этом браузере

### Requirement: REQ-BU-2 — Создание и открытие доски

Создание через «Новая доска» или карточку «Создать доску» SHALL переводить пользователя сразу на `/#/:slug`. Открытая по ссылке доска также добавляется в локальный каталог.

#### Scenario: Создание

- **WHEN** создание успешно
- **THEN** slug и полученные метаданные сохраняются и выполняется переход на созданную доску
- **AND** повторный клик во время запроса невозможен

#### Scenario: Вставка ссылки

- **WHEN** пользователь вставляет `https://doskito.app/#/abcdef12`, относительный `/#/abcdef12` или slug и нажимает «Открыть»/Enter
- **THEN** извлекается строго 8 строчных буквенно-цифровых символов и запрашивается board state
- **AND** при 200 доска сохраняется и открывается, при 404 показывается «Доска не найдена», при сетевой ошибке — отдельное сообщение
- **AND** произвольный текст и чужие path не принимаются как slug

### Requirement: REQ-BU-3 — Карточка доски

Карточка SHALL соответствовать `design/screens/boards-list.html`: цветной инициал имени, название, прогресс-бар, «X из Y задач готово», относительное `updatedAt`, меню `···` и «Скопировать ссылку».

#### Scenario: Открытие и копирование

- **WHEN** пользователь кликает карточку вне элементов управления
- **THEN** открывается доска
- **AND** «Скопировать ссылку» копирует `${window.location.origin}/#/${slug}`, не открывает доску и показывает success/error feedback
- **AND** production host не зашит в клиентский код

#### Scenario: Меню доски

- **WHEN** открыто меню `···`
- **THEN** доступны «Переименовать», «Удалить доску» и «Убрать из списка»
- **AND** «Убрать из списка» меняет только localStorage и не удаляет серверные данные

#### Scenario: Предупреждение перед серверным удалением

- **WHEN** пользователь выбирает «Удалить доску» в списке или на самой доске
- **THEN** до DELETE открывается модальный предупреждающий экран с заголовком «Удалить доску для всех?»
- **AND** текст сообщает: «Доска „{name}“ станет недоступна для всех участников. Все задачи и черновики будут удалены. Ссылка перестанет работать. Это действие нельзя отменить.»
- **AND** доступны «Отмена» и опасная кнопка «Удалить для всех»; исходный фокус установлен на «Отмена», Escape закрывает экран без DELETE
- **AND** DELETE отправляется только после явного нажатия «Удалить для всех»

#### Scenario: Результат подтверждения удаления

- **WHEN** DELETE успешен
- **THEN** slug удаляется из локального каталога, открытая доска закрывается и выполняется возврат к списку с toast «Доска удалена для всех участников»
- **AND** при ошибке доска остаётся в списке, предупреждение показывает ошибку и позволяет повторить запрос
- **AND** повторный submit блокируется на время запроса

### Requirement: REQ-BU-4 — Тексты и визуальные состояния

Экран SHALL содержать «Мои доски», подзаголовок «Список хранится только в этом браузере: доступ к доске даёт ссылка.», кнопку «Новая доска», input «Вставьте ссылку на доску» и «Открыть».

#### Scenario: Дисклеймер и сетка

- **WHEN** список отображается
- **THEN** внизу указано «Доски без активности 30 дней удаляются. Не делитесь ссылкой с теми, кому не доверяете: она даёт полный доступ.»
- **AND** используются цвета, шрифты, карточки, hover/focus и staggered `pop` из макета
- **AND** на широком экране сетка имеет 3 колонки с gap 20px, на узком — 1–2 без overflow

#### Scenario: Reduced motion

- **WHEN** включён `prefers-reduced-motion`
- **THEN** анимации появления и необязательные переходы отключены

### Requirement: REQ-BU-5 — Будущие email-уведомления

Email MUST NOT запрашиваться или отправляться в MVP. Комментарии в коде не заменяют требование и не создают небезопасный placeholder endpoint.

#### Scenario: Поведение MVP

- **WHEN** доска создана или пользователь приглашён
- **THEN** доступна только ссылка для копирования; никакие email-запросы не выполняются
