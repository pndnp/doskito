# Welcome Screen

## Purpose

Первый экран для пользователя без досок в localStorage. Он соответствует `design/screens/welcome.html` и ведёт в тот же flow создания/открытия, что Boards UI.

## ADDED Requirements

### Requirement: REQ-WS-1 — Логика отображения

Welcome SHALL показываться на `/` только при пустом валидном локальном каталоге. Прямой переход на валидный `/#/:slug` не перенаправляется на Welcome.

#### Scenario: Нет досок

- **WHEN** пользователь открывает `/` с пустым каталогом
- **THEN** показываются Welcome, «Создать доску» и поле «Уже есть ссылка?»

#### Scenario: Доски есть

- **WHEN** каталог содержит хотя бы один slug
- **THEN** показывается Boards UI без промежуточного Welcome

#### Scenario: Создание первой доски

- **WHEN** «Создать доску» завершилось успешно
- **THEN** доска сохраняется локально и открывается `/#/:slug`, а не список
- **AND** при следующем посещении `/` показывается список

#### Scenario: Открытие по ссылке

- **WHEN** пользователь нажимает «Открыть»
- **THEN** применяются общие правила валидации, GET board state, сохранения и ошибок из REQ-BU-2

### Requirement: REQ-WS-2 — Тексты и элементы макета

Welcome SHALL содержать логотип «Доскито», H1 «Создайте доску», описание, CTA и три pill-преимущества из макета.

#### Scenario: Точные тексты

- **WHEN** отображается Welcome
- **THEN** описание равно «Пишите задачи как в заметках, а ИИ разберёт их на подзадачи со сроками. Регистрация не нужна: доступ к доске по ссылке.»
- **AND** pills содержат «Без регистрации», «ИИ разбирает задачи», «Совместная работа по ссылке»
- **AND** input имеет placeholder «Вставьте ссылку», кнопка — «Открыть»

### Requirement: REQ-WS-3 — Дизайн и доступность

Экран SHALL повторять макет: H1 Unbounded 40px, описание Nunito 17px, CTA высотой 60px с padding `0 40px` и тенью `0 5px 0 #B88A00`, тёмный фон и карточки-примеры с `pop`/`bob`.

#### Scenario: Адаптивность и reduced motion

- **WHEN** экран узкий либо включён `prefers-reduced-motion`
- **THEN** поля и pills переносятся без overflow, клавиатурный focus видим
- **AND** декоративные `pop`/`bob` и hover-анимации отключаются

#### Scenario: Ошибка создания

- **WHEN** создание или открытие не удалось
- **THEN** форма сохраняет введённую ссылку, показывает ошибку и позволяет повторить запрос
