# Proposal

## Why

Команды и фрилансеры тратят время на организацию задач в разрозненных инструментах. Нужен минималистичный совместный трекер, где задача формулируется свободным текстом, а ИИ автоматически разбивает её на подзадачи, определяет приоритет и дедлайн. Доступ к доскам по секретной ссылке — без регистрации и авторизации.

## What Changes

- **Канбан-доска** с тремя колонками (To Do / In Progress / Done) и drag-and-drop перемещением задач между ними
- **AI Parse** — ввод свободного текста превращается через промежуточный экран редактирования в основную задачу с приоритетом, дедлайном и тегами. Если ИИ или пользователь оставил 2–10 подзадач, каждая становится отдельной самостоятельной задачей в To Do с унаследованными приоритетом, дедлайном и тегами; вложенных подзадач у задач нет
- **Boards UI** — начальный экран (`/`) показывает список досок из localStorage браузера пользователя. Доска открывается по slug из URL или при вставке ссылки. На первом этапе доски хранятся локально; в будущем ссылка на каждую доску будет приходить пользователю на email (при создании доски и при приглашении)
- **Совместный доступ** по уникальному slug доски: любой, кто открывает ссылку, может добавить своё имя и начать работать
- **SSE-синхронизация** — все подключённые пользователи получают обновления в реальном времени (движение задач, новые задачи, присоединение пользователей)
- **Оптимистичные обновления** — UI меняется мгновенно, TanStack Query инвалидирует кэш при ошибке
- **Автоудаление неактивных досок** — доски без активности 30 дней помечаются soft-delete
- **Админ endpoint** — скрытый `/admin/boards` для просмотра всех досок
- **Docker Compose** — локальная разработка с hot reload, изолированные тесты и production-like запуск теми же образами для последующего переноса на VPS

## Capabilities

### New Capabilities

- `board-management`: создание, удаление и управление канбан-досками с доступом по секретной ссылке (`slug`)
- `task-parsing`: разбор свободного текста в структурированную задачу через LLM с промежуточным редактированием (черновик → финализация)
- `real-time-sync`: рассылка обновлений доски подключённым клиентам через SSE
- `task-board`: CRUD самостоятельных задач, drag-and-drop перемещение, оптимистичные обновления
- `boards-ui`: начальный экран с localStorage для локального каталога досок, будущая email-рассылка ссылок
- `welcome-screen`: первый запуск без сохранённых досок, создание первой доски и открытие доски по ссылке

## Impact

- Новый стек: Fastify + Prisma + TypeScript на бэкенде, React + TanStack Query + dnd-kit на фронтенде
- SQLite для хранения данных (быстрый старт, прозрачная миграция на PostgreSQL при масштабировании)
- Внешний LLM API: NeuralDeep, URL задаётся переменной окружения `NEURALDEEP_API_URL`
- SSE эндпоинт добавляет persistent connection per board
- Нет пользователя/роли — каждый клиент равноправен, безопасность через secrecy of slug
